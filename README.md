# Fazal Mahmud Hassan — Portfolio & CMS

Personal portfolio website with custom Content Management System (CMS) & Admin Dashboard.

## Features
- **Modern Dark Theme**: Space Grotesk & DM Sans typography with electric blue accents.
- **Dynamic Content Management (CMS)**: Interactive admin dashboard (`admin.html`) to manage experience, projects, publications, education, and skills.
- **SHA-256 Authentication**: Password protected lockscreen.
- **Zero Dependencies**: Lightweight, ultra-fast vanilla HTML/CSS/JS.

## Pages
- `index.html` — Homepage with Hero, Expertise, Experience, Featured Work, and Contact.
- `about.html` — Detailed biography, full career timeline, education, and categorized skills.
- `projects.html` — Research, academic publications (Springer), engineering projects, and volunteer work.
- `admin.html` — Password-protected CMS admin dashboard (`admin` default).

## Running Locally
Simply open `index.html` or `admin.html` in any web browser.
